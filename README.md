# Magazin Mercedes

Интернет-магазин автозапчастей и аксессуаров Mercedes-Benz

## Описание
Проект представляет собой веб-приложение для подбора и заказа товаров для автомобилей Mercedes-Benz

## Основной функционал
- Каталог товаров с разделением по категориям
- Поиск и фильтрация запчастей
- Корзина и оформление заказа
